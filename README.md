# Бот «Массаж будущего» — Михаил Новосёлов (Сочи)

Telegram-бот с воронкой продаж, лид-магнитом.

## Возможности

- **Воронка продаж**: приветствие → лид-магнит → услуги → запись
- **Лид-магнит**: бесплатный гайд «5 признаков, что телу нужна помощь»
- **Бизнес-баня**: 15-минутная диагностика перед сессией у вашей бани в Сочи
- **Услуги**: Первая встреча (5000 ₽), Массаж будущего (10000 ₽), Курс 4 сеанса (30000 ₽)
- **Свободные слоты** с учётом длительности
- **Синхронизация календарей**: слоты фильтруются по локальным заявкам, календарю Uni-Q и календарю DIKIDI
- **Ссылки** на Dikidi и сайт
- **Обо мне** + контакты
- Заявки в SQLite + уведомление админу
- **/score** для администратора: оценка бота до 10/10 и зоны роста
- **/orchestra** для администратора: разложение задачи на субагентов

## Команды администратора

- `/score [days]` — оценка бота по инфраструктуре, воронке, записи, доверию, голосу, аналитике и управлению.
- `/sync_status [ДД.ММ.ГГГГ]` — проверить подключение календарей Uni-Q и DIKIDI.
- `/block ДД.ММ.ГГГГ ЧЧ:ММ МИНУТЫ [причина]` — вручную закрыть слот Uni-Q, если нет доступа к календарю коворкинга.
- `/blocks [ДД.ММ.ГГГГ]` — показать ручные блокировки на дату.
- `/unblock ID` — снять ручную блокировку.
- `/orchestra <задача>` — агент-оркестратор: цель, минимальная цепочка субагентов, скиллы, результат и правило безопасности.
- `/cert` — создать подарочный сертификат PDF.

Субагенты в `/orchestra` не отправляют сообщения клиентам, не публикуют посты,
не меняют цены и не удаляют данные. Финальное действие подтверждает человек.

## Синхронизация календарей Uni-Q + DIKIDI

Бот показывает свободные слоты только если время проходит два фильтра:

1. попадает в свободное окно Uni-Q, если задан `UNIQ_AVAILABILITY_URL`;
2. не занято в DIKIDI/«Массаж будущего», локальных заявках и блокировках.

Что считается занятым:

1. в локальных заявках SQLite;
2. в ручных блокировках Uni-Q;
3. в календаре Uni-Q по нужным ресурсам: `кушетка`, `душ`;
4. в календаре «Массаж будущего» DIKIDI.

DIKIDI поддерживает синхронизацию журнала записей с Google Calendar. Практический
вариант: подключить DIKIDI к Google Calendar, подключить календарь Uni-Q или
дать JSON-фид занятости, а затем передать эти данные боту.

Переменные окружения:

- `GOOGLE_SERVICE_ACCOUNT_JSON` — JSON сервисного аккаунта Google, если один доступ подходит для всех календарей.
- `GOOGLE_CALENDAR_ID` — обратная совместимость: календарь DIKIDI/Массаж будущего.
- `UNIQ_GOOGLE_SERVICE_ACCOUNT_JSON` — отдельный JSON сервисного аккаунта для Uni-Q, если нужен.
- `UNIQ_GOOGLE_CALENDAR_ID` — Google Calendar ID календаря Uni-Q с ресурсами `кушетка` и `душ`.
- `DIKIDI_GOOGLE_SERVICE_ACCOUNT_JSON` — отдельный JSON сервисного аккаунта для DIKIDI, если нужен.
- `DIKIDI_GOOGLE_CALENDAR_ID` — Google Calendar ID календаря DIKIDI/Массаж будущего.
- `UNIQ_CALENDAR_URL` — JSON-фид занятости Uni-Q. Можно использовать `{date}` или `{date_iso}` в URL.
- `UNIQ_CALENDAR_TOKEN` — bearer-токен, если нужен.
- `UNIQ_AVAILABILITY_URL` — JSON-фид свободных окон Uni-Q. Если задан, бот показывает только слоты внутри этих окон.
- `UNIQ_AVAILABILITY_TOKEN` — bearer-токен для фида свободных окон Uni-Q, если нужен.
- `UNIQ_REQUIRED_RESOURCES` — ресурсы через запятую, по умолчанию `кушетка,душ`.
- `DIKIDI_CALENDAR_URL` — JSON-фид занятости вашего DIKIDI.
- `DIKIDI_CALENDAR_TOKEN` — bearer-токен, если нужен.
- `CALENDAR_TIMEZONE` — часовой пояс, по умолчанию `Europe/Moscow`.
- `CALENDAR_SYNC_TIMEOUT` — таймаут запроса, по умолчанию `8`.

Минимальный рабочий вариант с Google Calendar: задать `GOOGLE_SERVICE_ACCOUNT_JSON`,
`UNIQ_GOOGLE_CALENDAR_ID` и `DIKIDI_GOOGLE_CALENDAR_ID`.

Если у Uni-Q нет Google Calendar, но есть список свободного времени, используйте
`UNIQ_AVAILABILITY_URL`: бот будет показывать только свободные окна Uni-Q и
вычитать занятость DIKIDI/«Массаж будущего».

Если у Uni-Q есть только занятость, используйте `UNIQ_CALENDAR_URL`.

Если доступа к календарю Uni-Q нет, используйте ручные блокировки:

```bash
/block 28.08.2026 14:00 90 Uni-Q кушетка и душ заняты
/blocks 28.08.2026
/unblock 1
```

Такие блокировки хранятся в SQLite и не показывают клиенту занятое время.

Фид может вернуть список событий или объект с ключом `items`, `events`,
`records`, `appointments`, `bookings`, `slots`, `windows` или `availability`.
Событие может содержать `start`/`end` в ISO-формате или `date` + `time`, а
также `duration_min`.

Готово к использованию.

## Railway deployment

Проект использует Dockerfile и Python 3.12 (Debian Bookworm). Railway должен собирать Dockerfile напрямую; runtime.txt не используется.

Required variables in Railway:
- BOT_TOKEN
- ADMIN_ID

Start command is already defined in Dockerfile: `python -u bot.py`.
