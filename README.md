# Бот «Массаж будущего» — Михаил Новосёлов (Сочи)

Telegram-бот с воронкой продаж, лид-магнитом.

## Возможности

- **Воронка продаж**: приветствие → лид-магнит → услуги → запись
- **Лид-магнит**: бесплатный гайд «5 признаков, что телу нужна помощь»
- **Бизнес-баня**: 15-минутная диагностика перед сессией у вашей бани в Сочи
- **Услуги**: Первая встреча (5000 ₽), Массаж будущего (10000 ₽), Курс 4 сеанса (30000 ₽)
- **Свободные слоты** с учётом длительности
- **Ссылки** на Dikidi и сайт
- **Обо мне** + контакты
- Заявки в SQLite + уведомление админу
- **/score** для администратора: оценка бота до 10/10 и зоны роста
- **/orchestra** для администратора: разложение задачи на субагентов

## Команды администратора

- `/score [days]` — оценка бота по инфраструктуре, воронке, записи, доверию, голосу, аналитике и управлению.
- `/orchestra <задача>` — агент-оркестратор: цель, минимальная цепочка субагентов, скиллы, результат и правило безопасности.
- `/cert` — создать подарочный сертификат PDF.

Субагенты в `/orchestra` не отправляют сообщения клиентам, не публикуют посты,
не меняют цены и не удаляют данные. Финальное действие подтверждает человек.

Готово к использованию.

## Railway deployment

Проект использует Dockerfile и Python 3.12 (Debian Bookworm). Railway должен собирать Dockerfile напрямую; runtime.txt не используется.

Required variables in Railway:
- BOT_TOKEN
- ADMIN_ID

Start command is already defined in Dockerfile: `python -u bot.py`.
